# MagicKeyWin — Apple Magic Keyboard Companion для Windows

Легковажна нативна утиліта на Rust для повноцінної інтеграції клавіатур **Apple Magic Keyboard 2** та **Magic Keyboard with Numeric Keypad** у середовищі Windows 10/11 без необхідності встановлення сторонніх або непідписаних драйверів режиму ядра (`TESTSIGNING`).

---

## 🚀 Основні можливості

* **Пряме керування гучністю через Windows Core Audio API (`IAudioEndpointVolume`):**
  * Виключає проблему «відвалу» кнопок регулювання звуку після сну чи повторного підключення Bluetooth.
  * Гучність регулюється напряму на рівні аудіопристрою Windows, не перехоплюється браузерами (Chrome, Edge) чи медіаплеєрами (Spotify, SMTC).

* **Повна підтримка клавіш F1 — F19:**
  * **Нативні дії F-клавіш у мультимедійному режимі:** можливість призначити будь-яку стандартну функціональну дію (`F1 Довідка`, `F2 Перейменувати`, `F3 Пошук`, `F4`, `F5 Оновити сторінку`, `F6 Фокус`, `F7..F10`, `F11 На весь екран`, `F12 DevTools / Інструменти розробника`, а також `F13..F19`) на будь-яку фізичну кнопку.
  * **Мультимедійні та системні дії:** збільшення/зменшення гучності, вимкнення звуку (Mute), відтворення/пауза, наступний/попередній трек, огляд вікон Task View (`Win+Tab`), пошук Windows (`Win+S`), створення скріншоту (`Win+Shift+S`), калькулятор, блокування екрана (`Win+L`).
  * **Запис та прив'язка власних хоткеїв:** можливість призначити довільне комбіноване сполучення клавіш (наприклад, `Ctrl+C`, `Win+D`, `Alt+F4`, `Ctrl+Shift+Esc` тощо) на будь-яку клавішу F1–F19.

* **Спливаючий HUD-оверлей (OSD):**
  * Напівпрозора темна картка зі шкалою рівня гучності та назвою виконаної дії.
  * Працює в неблокуючому прозорому режимі (`WS_EX_LAYERED | WS_EX_NOACTIVATE | WS_EX_TRANSPARENT`), не перехоплює фокус вводу в активних програмах та іграх.
  * Автоматично згасає через 1.3 секунди. Може бути вимкнений у налаштуваннях.

* **Зручний системний трей:**
  * Високоякісна піксельна high-DPI іконка клавіатури Apple біля годинника.
  * Швидке контекстне меню: відображення поточної гучності, перемикання режимів Mac/PC, відкриття налаштувань, вихід.

* **Два режими роботи:**
  * **Mac Mode (за замовчуванням):** верхній ряд виконує призначені мультимедійні дії, хоткеї або обрані нативні F-клавіші.
  * **PC Mode:** клавіші F1–F12 працюють як стандартні клавіші Windows.
  * Перемикання доступне з меню трею, через конфігуратор або гарячою кнопкою.

* **Автозавантаження разом із Windows:**
  * Просте ввімкнення/вимкнення через прапорець у конфігураторі (запис у гілку `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).

* **Низьке споживання ресурсів:**
  * Пам'ять: ~12 МБ ОЗП.
  * Навантаження на процесор: 0.0% у режимі очікування.
  * Один компактний автономний `.exe` файл (~2 МБ) без консольного вікна (`#![windows_subsystem = "windows"]`) і без потреби в зовнішніх бібліотеках чи середовищах виконання.

## 🖥️ Використання

1. Запустіть файл `magic-key-win.exe` — у системному треї (біля годинника) з'явиться значок клавіатури.
2. Подвійний клік по значку (або правий клік → **«Налаштування...»**) відкриває двоколонковий графічний конфігуратор.
3. У конфігураторі ви можете:
   * Вибрати будь-яку дію зі списку для кожної клавіші від **F1 до F19**.
   * Натиснути кнопку **«Хоткей»** для запису власної комбінації клавіш.
   * Увімкнути/вимкнути оверлей OSD, режим Mac та автозавантаження.
   * Перевірити правильність розпізнавання клавіш у живому тестері скан-кодів.
4. Натисніть **«Зберегти»** — налаштування негайно набудуть чинності та запишуться у файл `magic_key_config.json`.

## 🛠️ Збірка з вихідного коду

Для компіляції знадобиться встановлений [Rust](https://rustup.rs/) (Windows MSVC toolchain):

```powershell
# Клонування репозиторію
git clone https://github.com/grblmmbg-pixel/magic-key-win.git
cd magic-key-win

# Перевірка та запуск тестів
cargo test

# Компіляція релізної оптимізованої версії
cargo build --release
```

Готовий виконуваний файл розташовуватиметься за шляхом:
`target\release\magic-key-win.exe`

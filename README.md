# MagicKeyWin — Apple Magic Keyboard Companion для Windows

Легковесная нативная утилита на Rust для полноценной интеграции клавиатур Apple Magic Keyboard 2 / Magic Keyboard with Numeric Keypad на Windows 10/11 без необходимости установки драйверов режима ядра (`TESTSIGNING`).

## Возможности
* **Прямое управление звуком через Windows Core Audio API:** исключает проблему "отваливания" громкости и перехвата браузерами (Chrome/Edge/Spotify).
* **Поддержка полного ряда F1 — F19:**
  * **Нативные действия F-клавиш в мультимедиа режиме:** возможность назначить любую функциональную клавишу (`F1 Справка`, `F2 Переименовать`, `F3 Поиск`, `F4`, `F5 Обновить страницу`, `F6 Фокус`, `F7..F10`, `F11 Полный экран`, `F12 DevTools`, а также `F13..F19`) на любую физическую кнопку.
  * **Системные медиа-действия:** громкость, mute, play/pause, prev/next track, Task View, поиск, скриншот, калькулятор, блокировка.
  * **Запись и назначение произвольных хоткеев:** (например `Ctrl+C`, `Win+D`, `Alt+F4`, `Ctrl+Shift+Esc` и т.д.) на любую клавишу.
* **Всплывающий HUD-оверлей (OSD):** полупрозрачная карточка со шкалой громкости и индикацией выполняемых действий.
* **Автозагрузка:** галочка в настройках для автоматического старта вместе с Windows (`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`).
* **Два режима работы F1–F12:**
  * **Mac Mode (по умолчанию):** F1–F12 сразу выполняют назначенные мультимедиа-действия или хоткеи.
  * **PC Mode:** F1–F12 работают как стандартные клавиши Windows.
  * Быстрое переключение режимов доступно прямо из меню трея.
* **Ресурсы:** ~12 МБ ОЗУ, 0% CPU в режиме ожидания.
* **Размер:** один компактный `.exe` файл (~2 МБ), не требует внешних библиотек и рантаймов.

## Использование
1. Запустите `magic-key-win.exe` — появится значок клавиатуры в системном трее (возле часов).
2. Двойной клик по иконке в трее (или правый клик -> **«Настройки...»**) открывает конфигуратор.
3. В конфигураторе можно настроить действие для любой клавиши от **F1 до F19**, нажать кнопку **«Хоткей»** для записи своего сочетания, включить/выключить автозагрузку и оверлей.
4. Нажмите **«Сохранить»** — настройки сразу вступят в силу и сохранятся в `magic_key_config.json`.
